# @local/dsh-naiyou-pet 2.1.0

DeepSeek Harness 的本地奶邮宠物插件。建议使用发行包上一级的 `install.cmd` 安装和 `uninstall.cmd` 卸载。

插件依赖 Harness 提供的会话、投影与 Agent 服务，读取批准事件和官方 Token 汇总。在 Windows 上使用系统 Windows PowerShell/WPF 显示桌面浮窗，网页客户端保留窗口内宠物。不包含平台程序或 API Key。

完整安装和使用说明在发行包的 `dsh/README.md`（独立 DSH ZIP 中为根目录 `README.md`）。
